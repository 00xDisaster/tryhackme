## How to Use This Repository

1. Navigate to the room folder you're interested in
2. Each folder contains a README.md with:
   - Room information and difficulty
   - Step-by-step solution
   - Useful commands and techniques
   - Answers to questions (hidden with spoiler tags when possible)
   - Additional notes and learning points

## Contributing

Feel free to add your own solutions by:
1. Creating a new folder with the room name
2. Adding a README.md with your solution
3. Updating this main README with a link to your room

## Disclaimer

These solutions are for educational purposes only. Always try to solve the rooms yourself first before looking at the solutions!
